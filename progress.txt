## Codebase Patterns
- Header navigation uses snippets/header-drawer.liquid for drawer menu system
- Menu styling controlled by assets/component-menu-drawer.css
- Menu uses details/summary HTML structure for toggle functionality
- Standard Shopify theme: direct edits to Liquid templates and CSS, no build tools
- CSS can target details[open] and details:not([open]) for state-based styling
- Footer included via `{% sections 'footer-group' %}` in layout/theme.liquid
- Body tag has template-specific classes (e.g., `custom-home` for homepage) for targeted styling
- Footer configuration: sections/footer-group.json controls padding, social icons, and other settings
- Typography for luxury aesthetic: 1.1rem base, uppercase headings, letter-spacing: 0.1em

## 2026-01-22 - Story 12
- Fixed menu scroll issue on desktop and mobile by changing overflow property
- Files changed:
  - assets/component-menu-drawer.css: Changed overflow-y from 'clip' to 'auto' on .menu-drawer__navigation-container
- **Learnings for future iterations:**
  - The menu drawer was using overflow-y: clip which prevented scrolling when content exceeded viewport height
  - The .menu-drawer__navigation-container is the scrollable container that holds the menu items
  - overflow-y: auto allows scrolling when content overflows while keeping it hidden when content fits
  - No JavaScript changes were needed - this was purely a CSS overflow issue
  - The menu drawer uses a grid layout with grid-template-rows: 1fr auto to position menu and utility links
