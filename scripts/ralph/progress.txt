## Codebase Patterns
- Footer menu uses nested Shopify menu structure: parent items are column headers (don't link), children are the actual links
- CSS uses rgba(var(--color-foreground), 0.X) pattern for opacity variations on text colors
- Homepage styling uses `.custom-home` class on body element (set in theme.liquid when template == 'index')
- Localization uses `localization-form` custom element with Shopify's built-in localization snippets
- Font sizes use rem units (typically 1.1rem-1.2rem for body text, letter-spacing: 0.05em-0.15em)
