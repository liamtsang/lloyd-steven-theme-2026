## Codebase Patterns
- Footer menu uses nested Shopify menu structure: parent items are column headers (don't link), children are the actual links
- CSS uses rgba(var(--color-foreground), 0.X) pattern for opacity variations on text colors
- Homepage styling uses `.custom-home` class on body element (set in theme.liquid when template == 'index')
- Localization uses `localization-form` custom element with Shopify's built-in localization snippets
- Font sizes use rem units (typically 1.1rem-1.2rem for body text, letter-spacing: 0.05em-0.15em)
- Product grid uses flexbox by default (`.grid` class in base.css). To span items across multiple rows+columns, use CSS Grid via an override class — never modify `base.css` `.grid` directly
- `--header-height` CSS variable is set by `sections/header.liquid` JS and used for sticky positioning offsets
- Section blocks with `limit: 1` restrict to a single block instance in the theme editor
- Use `{{ block.shopify_attributes }}` on block wrappers to enable theme editor selection/highlighting
- Working directory has trailing space in name (`Lloydsteven Theme 2026 `) — use explicit git paths with quotes

- **Learnings for future iterations:**
  - Flexbox (`.grid` in `base.css`) cannot span items across rows+columns — CSS Grid is needed, but must be applied via an additive class to avoid site-wide regression

  - Must also reset `.grid__item { width: auto; max-width: none }` when switching from flex to grid, because the old `calc(33.33% - ...)` widths conflict with CSS Grid's `1fr` columns
  - `position: sticky` on the image works because the parent `<li>` spans 3 rows (taller than viewport), so the sticky child can pin while the parent scrolls
  - The working directory name has a trailing space, causing path issues with some tools — always use explicit quoted paths for git commands
